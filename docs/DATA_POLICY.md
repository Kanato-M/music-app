# データの扱い方針（法的に安全な引用ルール）

ChordWiki・U-FRET・リンネのコードブック・コード進行メモ倉庫などのコード譜サイトは、
本アプリでは **「参照先・リンク先」** として扱います。

## やらないこと

- **歌詞の掲載**（一部でも不可）。歌詞は著作物です。
- **コード譜ページの転載・スクレイピング・自動収集**。各サイトの譜面は歌詞・レイアウトと一体の編集物であり、
  利用規約で転載や機械的な収集を禁じている場合があります。
- 各サイトのロゴ・デザインの流用、公式と誤解される表示。

## やること

1. **コード名の並び（事実情報）だけを独自に書き起こす。** 個々のコードやありふれた進行は、一般に著作権の保護対象になりにくい情報です。
   公開情報を参照し、本アプリのデータ形式で改めて記述します。
2. **解説はオリジナル。** 理論解説・分析文はすべて本アプリで執筆します。
3. **出典の明示とリンク。** 参照したページ・参照日を曲ごとに記録し（`sources`, `accessed`）、正確な譜面は元のサイトへ誘導します。
4. **引用の4要件（著作権法32条）を守る。** 他サイトの文章等をやむを得ず引用する場合は
   ①主従関係（本文が主）②明瞭区別 ③出所の明示 ④必要最小限 を満たします。
5. **確度を表示する。** セクションごとに「照合済み／推定」を表示し、誤りを訂正できるようにします。
6. **ユーザー入力は端末内に保存。** 「コードを入力」機能の内容はブラウザの localStorage にのみ保存し、外部送信しません。

## 外部サイトとの連携

- 検索：各サイトの検索ページ（または `site:` 指定の Web 検索）へのリンクを生成するだけで、サーバー側で取得はしません。
- 将来、各サイトと API 連携・データ提供契約を結べた場合のみ、その条件の範囲で自動取得を検討します。

> 本ドキュメントは方針の説明であり、法的助言ではありません。公開・商用化の前に各サイトの最新の利用規約を確認し、
> 必要に応じて専門家に相談してください。
