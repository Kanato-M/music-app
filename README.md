# コード進行ラボ（モックアップ）

曲名を検索すると、その曲の **コード・コード進行（2-5-1 などのディグリー）・キーと転調・使われている音楽理論** を学べる Web アプリです。

モックアップとして **BUMP OF CHICKEN「スノースマイル」** を収録しています。

## 起動

依存パッケージはありません（Node.js 18 以上）。

```bash
npm start        # http://localhost:5173
npm test         # 理論エンジンと曲データのテスト
```

## 機能

| 画面 | 内容 |
| --- | --- |
| 曲を探す | 曲名・読み・アーティストで検索。未収録の曲は ChordWiki / U-FRET / リンネのコードブック / コード進行メモ倉庫 の検索リンクを表示 |
| 曲ページ › コード譜 | セクションごとのコード（歌詞なし）。コード名／度数の切替、移調、半音下げチューニングのフォーム表示、機能（T/SD/D）とノンダイアトニックの色分け、タップで発音＆解説、セクション再生 |
| 曲ページ › コード進行 | 2-5-1・王道進行・カノン・小室進行などの自動検出、下行／上行ベースライン、ノンダイアトニックコードの分類（セカンダリードミナント、借用和音、パッシングディミニッシュ、♯IVm7-5 など）、度数の使用回数 |
| 曲ページ › キー・転調 | キーのタイムライン、転調の有無、チューニングとカポ位置、ダイアトニックコード表 |
| 曲ページ › 解説 | 曲のポイントごとのオリジナル解説（理論レッスンへのリンク付き） |
| 曲ページ › 出典 | 参照した情報源と参照日、各サイトへのリンク |
| 音楽理論 | ディグリー、ダイアトニック、機能、2-5-1、有名進行、分数コード、セカンダリードミナント、借用和音、パッシングディミニッシュ、♯IVm7-5、転調、移調とチューニング（例は再生可能） |
| コードを入力 | 自分でコードを入力して同じ解析を実行（キー自動判定）。マイリストに保存（ブラウザ内のみ） |

## 構成

```
index.html
css/style.css
src/theory.js      理論エンジン（コード解析・移調・度数・ダイアトニック判定・分類・進行検出・キー推定）
src/app.js         画面（ハッシュルーティング）
src/audio.js       Web Audio によるコード再生
src/lessons.js     理論レッスン
src/sources.js     外部サイトの検索リンク
data/songs/*.js    曲データ（歌詞なし。コード・解説・出典）
tests/             node:test によるテスト
docs/DATA_POLICY.md  データの扱い方針（引用ルール）
```

## 曲の追加方法

`data/songs/snow-smile.js` を参考に `data/songs/<id>.js` を作り、`data/songs/index.js` に登録します。
譜面は `| C | G/B | Am7 | F |` 形式（1 小節に複数コードは空白区切り）。
各セクションには確度（`referenced` 照合済み / `estimated` 推定）を付けてください。

## データの扱い

歌詞・コード譜ページの転載やスクレイピングは行いません。詳しくは [docs/DATA_POLICY.md](docs/DATA_POLICY.md)。
